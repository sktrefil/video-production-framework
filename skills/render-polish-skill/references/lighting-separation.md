# Lighting Separation

Lighting polish improves readability; it does not redesign the shot.

Default delta:
- exposure change: LOW
- contrast change: LOW
- direction change: PROHIBITED
- color temperature shift: MINIMAL

For EXIT_MATCH and CONTINUATION:
- preserve source direction
- preserve dominant temperature family
- preserve relative brightness hierarchy

Avoid:
- heavy bloom
- excessive rim light
- new fantasy light sources
- global flattening
- dramatic relighting for aesthetics alone
