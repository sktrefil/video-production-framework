# History Mystery Scriptwriter

Develops fact-checked historical research into a TTS-friendly, curiosity-led narration **together with directing handoff metadata**.

It is intentionally upstream of final TTS. The script is revised against `DIRECTING_PREFLIGHT` before it can become a lock candidate.
