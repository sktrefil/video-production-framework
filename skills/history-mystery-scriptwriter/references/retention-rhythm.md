# Retention Rhythm

Use curiosity without sensationalism.

- Open the core question early.
- Do not answer a question in the same breath if a real clue can intervene.
- Aim for a meaningful evidence/question/interpretation change before a long static explanation develops.
- Alternate BUILD, REVEAL, EXPLAIN, REDIRECT, HOLD, PAYOFF rather than escalating continuously.
- After a payoff, either deepen the consequence or change scale; do not restate the same result.
- Long technical method passages must earn their time by changing confidence, interpretation, or evidence reliability.
