# 연결·실행 규칙

## 자산 방식
- SINGLE: 시작 이미지 한 장으로 생성하라.
- START_TARGET: 시작과 목표 끝 이미지를 둘 다 지원할 때 사용하라.
- CONTINUATION: 공급자의 실제 클립 확장 기능을 지원할 때 사용하라.
- EXIT_REFERENCE: 이전 클립의 실제 끝 프레임을 추출해 새 클립 시작 이미지로 사용하라. 확장 기능과 혼동하지 말라.
- GRAPHIC_COMPOSITE: 고정 레이어·마스크·2D 패럴랙스·편집으로 구성하라. 이것은 생성 I2V가 아니라 합성 대안임을 표시하라.

## 연결 확인
각 경계의 이전 끝과 다음 시작에서 다음 항목을 비교하라.
1. 주 대상 정체성·외형·화면 x/y·스케일.
2. 공간 기준점·전경 가림막·배경 배치.
3. 이동 방향·카메라 속도·가속 또는 의도적 정지.
4. 공개 전/후 상태와 아직 숨긴 단서.
5. 접촉음·반복 리듬·잔향의 타이밍.
허구적 공간 변형도 스스로 정의한 규칙 안에서 이어지게 하라. 그림의 작은 질감 변화는 주 대상 의미를 바꾸지 않으면 NOTE로 남기라.

## 실패 처리
- 전송·서비스 오류: 같은 입력으로 재시도하고 서비스 실패로 기록하라.
- 연출·정체성 오류: 관련 카드와 프롬프트를 새 revision으로 만들라.
- 같은 창작 실패가 두 번 반복되면 경로를 단순화하거나 시작/끝 구도·레이어 합성 방식으로 바꾸라. 동일 프롬프트를 무한 반복하지 말라.
- 형상 변화가 핵심 공개를 훼손하면 트림만으로 숨기지 말라. 국소 합성이나 해당 클립 재제작을 선택하라.
- 유효한 결과가 없으면 실패 항목을 보존하고 도구 부재/실패를 알리라. 정지 이미지 팬·줌 합성을 완성 I2V로 보고하지 말라.

## 기능 근거
도구 이름과 근거를 현재 환경에서 발견하라. 접근 권한·계정·비용·사용량 제한이 필요한 경우 실제 작업을 가로막는 것만 알리라. 사용자 요청으로 이미 허용된 작업에 재확인을 남발하지 말라. 지원 도구가 없을 때는 플러그인 탐색 기능이 제공되면 그 지침을 사용하고, 도구가 발견되지 않으면 계획과 차단 상태를 제공하라.
