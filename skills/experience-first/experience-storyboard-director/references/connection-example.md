# 연결 예시

허구의 이중 가림막 장면을 예로 사용하라. 실제 역사적 장치라고 쓰지 말라.

- B01 끝: 패널 오른쪽 이음선 x=0.65, 전경 기둥이 오른쪽 가장자리, 카메라 우측 이동, 먹먹한 두드림.
- B02 시작: 같은 이음선·기둥 위치와 우측 이동을 유지하라. 기둥이 화면을 가린 동안 클립을 연결할 수 있다.
- B02 공개: 기둥이 왼쪽으로 지나가면 얇은 패널 단면과 후경 통로를 공개하라. 패널을 새 문으로 변형하지 말라. 두드림을 오른쪽의 직접음으로 바꾸되 모노에서는 음색으로 구분하라.
- B02 끝: 오른쪽에서 패널에 접촉하는 물체가 빠져나간다.
- B03 시작: 같은 물체·이동 방향을 연결하라. 다른 장소를 같은 방향의 물체로 연결할 경우 MATCH_CUT로 표시하고 장소 차이를 읽을 단서를 두라.

STORY에는 관객이 알게 된 원인을, FRAME에는 그 원인을 볼 배치를, MOTION에는 공개를 만드는 움직임을, EXIT에는 다음 비트를 읽을 연결을 적으라. 어려운 연속 카메라를 고정 2D 레이어의 패럴랙스로 바꾸어도 지각 변화가 유지되는지 판단하라.
