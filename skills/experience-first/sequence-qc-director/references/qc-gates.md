# 검수·통과 규칙

## 두 가지 문
PRE_PRODUCTION의 설계 PASS는 실행 계획이 충분하다는 뜻이다. 실제 클립과 연결 영상을 보았다는 뜻이 아니다.
PILOT_REVIEW의 PASS는 실제 20~30초 연결 영상으로 경험을 확인한 결과다. 이것만 6번 내레이션 잠금을 허용한다.

## 필수 실제 통과 조건
- 입력이 같은 프로젝트의 승인된 최신 revision으로 연결된다.
- 실제 연결 영상 경로와 확인 가능한 파일 정체성·실측 길이가 있다.
- 실제 길이가 20~30초이며 핵심 공개와 적어도 한 클립 경계가 포함된다.
- 연속 시간 흐름의 영상과 임시 음향을 실제로 검토했다.
- 첫 3~4초의 관심 변화와 관객 경험 조건이 실제로 보이고 들린다.
- 사실·허구 구분, 스타일, 주요 대상 정체성, 공개 순서가 유지된다.
- 중요 결함이 해결됐고 변경 구간의 앞뒤 경계를 다시 검토했다.
- 실제 관찰 타임코드·검사 방식·검토 revision이 남아 있다.

프레임샘플은 공간·형상·공개 상태를 확인하는 보조 근거로 사용하라. 시간 흐름과 음향 경험을 확인하지 못하면 미확인 항목을 명시하고 실제 통과를 보류하라. 실제 관객 검사는 별도이며 수행하지 않았으면 viewer_test: NOT_RUN으로 남기라. 자체 영상 검토를 실제 관객 평가로 표현하지 말라.

## 결함 심각도와 조치
- P0: 사실 반전, 허구의 사실화, 주요 대상 정체성 혼동, 다른 revision 사용. 해결 전 중단하라.
- P1: 단서가 읽히지 않음, 방향·공간 연결 충돌, 접촉음 엇갈림, 목적 없는 긴 정적 구간. 국소 편집으로 해결 가능하면 EDIT_FIX, 아니면 해당 클립/콘티 수정.
- P2: 작은 선·질감·장식 변화. 실제 노출 시간에서 의미와 화풍이 유지되면 PASS + NOTE.

심각도를 추측만으로 확정하지 말라. planned_risk와 observed_defect를 구분하라. 결함마다 clip_id/beat_id, 타임코드, 관찰, 관객에게 생기는 오해, 조치, 수정 담당 단계, 재검토 범위를 적으라.

## 반려 경로
경험 약함 → 1번.
주제 불일치·사실 근거 부족 → 2번.
단서 순서·공개·구도 실패 → 3번.
형상·방향·생성 실패 → 4번.
트림·소리·국소 합성으로 해결 가능 → 파일럿 편집 후 5번 재검토.
점수 총합으로 P0/P1을 상쇄하지 말라. 수정 목록을 완료 체크만 했다는 이유로 통과시키지 말고 수정 영상을 재검토하라.

## 출력 상태
- 사전 검토 통과 + 기능/자산 경로 확보: design_status PASS, pilot_status PLANNED, readiness READY_FOR_PILOT.
- 설계 문제: design_status REVISE, readiness REVISE_DESIGN.
- 실행/입력 누락: readiness BLOCKED. 설계가 충분하면 design_status PASS를 유지할 수 있다.
- 생성했지만 재생 미검토: pilot_status GENERATED_UNREVIEWED.
- 실제 중요 결함: pilot_status REVISE.
- 실제 검증 통과: pilot_status PASS, readiness READY_FOR_NARRATION, narration_gate.eligible true.
