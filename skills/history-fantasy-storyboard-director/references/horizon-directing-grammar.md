# Horizon-style Directing Grammar

This project uses a Horizon-inspired rhythm concept, not literal style copying.

## Core
- one meaningful story event per beat
- camera movement reveals information
- clean depth hierarchy
- frequent but purposeful focus shifts
- avoid repeated static compositions
- create pace through internal shot change, not only fast cutting

## Scale Rhythm
Examples:
- Wide -> Medium -> Detail -> Wide
- Medium -> Close -> Wide
- Tracking Wide -> Detail -> Environmental Reveal

## Minimum Change
Adjacent beats should normally change at least two:
- location
- shot size
- primary subject
- camera method
- depth pattern
- lighting/environment
- motion vector

## Foreground Function
Foreground should serve at least one:
- parallax
- reveal
- occlusion
- transition
