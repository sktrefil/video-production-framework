# Motion Readiness

A keyframe is approved only if it can support the planned video motion.

## H3 Core Check
Pass at least 3 of 4:
1. camera corridor is visible/usable
2. foreground parallax source exists when needed
3. subject has an executable motion vector
4. target/exit state is visually distinct

## Additional Checks
- no geometry blocks the intended path
- subject is not pinned into a poster-like center composition unless required
- camera direction has enough negative space
- START/TARGET relation is physically plausible
- motion can be completed within clip duration
- image detail does not obscure intended movement
