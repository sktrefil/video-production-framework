## 04 — 컷·TTS·타임라인

1. `r04`의 `tts_text`를 컷별 낭독 원문으로 사용한다. 문구를 바꾸면 새 대본 개정과 Story Gate 재검토가 필요하다. `story_event`와 화면 설명은 낭독하지 않는다.
2. 제작 직전에 `FINAL_TTS_GATE` 검증으로 r04/SDL-r04/PF04/VS03/SG01의 개정·해시와 Scene 승인을 다시 대조한다. 통과 전 MP3는 FINAL로 표기하지 않는다.
3. 기본 재생 속도는 **1.0×**. 19개 서사 컷 ID별로 분절 MP3를 만들고, 각 파일의 실제 발화 길이·발음·시작/종료 무음을 측정한다. 180초 및 현재 컷 시각은 **계획값**이다.
4. 발화의 핵심 단어별 공개 시점과 화면 행동을 맞춘다. 말이 끝나기 전에 의미 있는 영상 행동을 잘라내거나, 영상만 남아 설명 없는 긴 구간을 만들지 않는다. 부족한 길이는 우선 샷 사용 범위·시각적 호흡·자막 시작점으로 조정하며, 대본 변경은 별도 승인 절차로 돌린다.
5. 외부 가이드의 **실제 편집 샷 10초 이하** 기준을 적용한다. 현재 서사 컷 중 6개가 10초를 넘는다. 아래 A/B는 **하나의 승인 Scene 안에 제안하는 두 영상 샷**이며 새 대본·새 Scene이 아니다. 분할점은 TTS 실측 후 이동할 수 있다.

| 승인 서사 컷 | 계획 구간 | 계획 길이 | 검토용 영상 샷 분할 |
|---|---:|---:|---|
| `cut3_3` | 01:40–01:55 | 15초 | A 01:40–01:47.5, B 01:47.5–01:55 |
| `cut3_4` | 01:55–02:10 | 15초 | A 01:55–02:02.5, B 02:02.5–02:10 |
| `cut4_1` | 02:10–02:22 | 12초 | A 02:10–02:16, B 02:16–02:22 |
| `cut4_2` | 02:22–02:34 | 12초 | A 02:22–02:28, B 02:28–02:34 |
| `cut4_3` | 02:34–02:48 | 14초 | A 02:34–02:41, B 02:41–02:48 |
| `cut4_4` | 02:48–03:00 | 12초 | A 02:48–02:54, B 02:54–03:00 |

따라서 검토 대상은 **19개 낭독 단위와 25개 영상 샷**이다. 그 외 컷의 계획 길이는 5–10초다. 10초짜리 두 컷(`cut3_1`, `cut3_2`)은 편집 사용 길이를 넘기지 않도록 측정한다.

타임라인 계산은 `최종 영상 길이 = 샷별 실제 사용 길이 합 − 전환 겹침 길이 합`이다. 예를 들어 5.0초 샷 두 개를 0.3초 겹치면 9.7초가 된다. 0.3초 Cross Dissolve는 **기본 제안**일 뿐이며, 문자나 형태가 이중으로 보이면 Hard/Match Cut을 선택한다. 디졸브에는 양쪽 미사용 프레임(handle)이 필요하다. 최종 구간·전환·자막 시각은 실측 MP3 및 생성 영상의 실제 사용 프레임으로 다시 계산한다.

## 05 — 컷별 상세 프롬프트 계약

각 영상 샷은 아래 필드를 한 행/카드에 모두 가진다. 서사 컷과 샷을 분리해 기록하므로 A/B로 나뉘어도 낭독 문장과 Scene ID는 하나를 가리킨다.

| 필드 | 필수 내용 |
|---|---|
| Identity | `part_id`, 승인 `scene_id`, 승인 `cut_id`, `shot_id`, sequence ID, 서사 기능 |
| Timeline | 계획 시작·종료, 제안 사용 길이, **실측** TTS 길이(없으면 `PENDING`), 전환·handle |
| Script / Narration | 승인된 장면 의미·전후 맥락과 `tts_text`의 정확한 원문을 별도 필드로 기록 |
| Image | 피사체·수량·공간·샷 크기·초점/심도층·의미·조명·팔레트·카메라 이동 공간·연속성·금지 요소 |
| Motion | `STORY / FRAME / MOTION / EXIT`, 초별 주목·카메라 경로·속도 변화·피사체 행동·다음 컷 인계, 금지 동작 |
| References | 승인된 시퀀스 패널 경로·해시(현재 미승인), A–D 보드의 해당 역할, 이전 컷의 **실제 사용 종료 프레임**이 필요하면 그 경로·해시 |
| Edit / Audio | 전환 방식·오버랩, 자막·SFX·BGM 단서, TTS 매칭, 이미지/모션/음성 QC 상태 |

이미지 프롬프트는 **승인된 스타일 + 해당 시퀀스 참조 + 이 샷의 정확한 내용** 순서로 조립한다. `GIPC01`의 실제 `global_style_suffix`를 붙이고, 모델에서 지원할 때만 `--ar 16:9` 문법을 쓴다. 글자·날짜·라틴어 어구는 생성 이미지에 맡기지 않고 별도 편집 그래픽으로 합성한다. 영상 프롬프트는 이미지의 물체 위치와 카메라 이동 가능 공간을 그대로 따른다. 시작 이미지와 맞지 않는 물체 출현·문자 변형·미검증 역사 재연은 금지한다.

모션의 `EXIT`는 다음 샷의 시작 구도·방향·주목 대상을 명시한다. `CONTINUATION`이면 다음 START의 근거는 계획된 마지막 이미지가 아니라 **채택 영상에서 실제 편집에 사용한 마지막 프레임**이다. 실제 영상이 없는 현재 패키지에서는 `EXIT_TARGET_PROVISIONAL`로만 표시한다.

이 프로젝트에서는 사실로 확인되지 않은 요일별 살인·전투·침입 관습, 로마→한국어 신명 직계 전파, 가짜 라틴 비문을 영상으로 되살리지 않는다. A–D는 시각적 은유의 참조이며 실제 고대 사건 기록처럼 설명하지 않는다.

## 현재 검토 순서

1. 19컷의 이미지 내용과 25개 샷의 카메라·EXIT 제안을 확인한다. 특히 6개 A/B 분할점은 **실측 전 가안**이다.
2. 시퀀스별 마스터 보드를 현재 스타일로 새로 만들고 승인한다. 기존 A–D 네 컷 기준 보드를 4개 시퀀스의 승인 보드로 자동 간주하지 않는다.
3. FINAL TTS 게이트 검증 → 컷별 MP3 생성·실측 → 샷별 공개 시점·전환 길이 재조정 순으로 진행한다.
4. 승인된 보드와 실측 음성에 맞게 이미지/모션 프롬프트를 확정한 뒤 생성한다. 이미지 후보와 I2V 결과는 별도 QC를 거친다.
