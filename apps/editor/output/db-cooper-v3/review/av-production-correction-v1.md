# D.B. Cooper 음성·화면 연결 오류 원인과 제작 기준

상태: **제작 전 검수 기준 개정 / 기존 승인 상태 변경 없음**. `project.db`, FINAL 대본·Scene graph·TTS·원본 CL01–05는 수정하지 않았다.

## 왜 승인 후에도 어긋났나

1. Script Directing Lock과 관리자 Story Gate는 사건·대본·Scene 순서를 승인했다. 화면에서 계단·가방·종이가 실제로 보이는 초까지 승인한 기록은 아니었다.
2. FINAL TTS를 30샷에 빠짐없이 배치했지만, 검사는 주로 **샷 안에 음성이 들어가는 길이**를 확인했다. 핵심 명사·동사가 나오는 순간과 화면 공개 순간을 대조하지 않았다.
3. 실제 영상 생성 후 사용 구간의 프레임을 다음 START로 추출했지만, 누적 영상에 FINAL TTS를 얹어 문구·공개·다음 동작을 매번 검수하지 않았다.
4. 수동으로 만든 최신 프롬프트와 잠긴 `chain-plan.json`/jobs의 프롬프트 개정이 달라졌다. CL06은 최신 v4가 가방→통로 연출인데 연결 계획은 예전 v2를 가리킨다.

## 새 경량 게이트

1. **대본·Scene 승인**: 사건의 사실·순서·표현을 잠근다. 이 승인은 화면·음성 동기 승인이 아니다.
2. **FINAL TTS 이후, 첫 이미지 이전**: 모든 샷의 핵심 문구 발화 시작·끝, 해당 화면 공개 구간, 화면 주목 대상, 사용 종료 상태, 다음 START 상태를 한 계약에 적는다. `validate-longform-av-contract.py`로 30샷 전체를 검사한다. 프롬프트에 `AV_BEATS_JSON`을 넣어 계약과 영상 지시의 시점도 일치시킨다. 어긋나면 해당 샷의 연출·편집 배치를 먼저 고친다.
3. **러프 연결본**: 확정 TTS와 임시 화면으로 20~30초 단위 시퀀스를 보며 중복 모티프, 빈 시간, 사건의 역행을 검수한다. 통과 후 START·END·VIDEO 프롬프트를 같은 개정에서 준비한다.
4. **클립마다 실제 연결 검수**: 생성된 영상의 사용 구간에 FINAL TTS를 얹고 직전 클립부터 다음 START까지 재생한다. 실제 공개 시점과 마지막 사용 프레임이 계약을 지키는지 확인한 뒤 다음 START를 채택한다. 다르면 국소 편집 후보를 먼저 시험하고 필요할 때만 해당 클립을 새 프롬프트 개정으로 다시 만든다.

현재 쿠퍼 프로젝트는 새 클립을 저장한 뒤 다음 명령에서 마지막 클립 ID만 바꿔 누적 검수본을 만든다. 예를 들어 CL06 영상 생성 후에는 다음과 같다.

```powershell
python scripts/db-cooper-cl01-05-av-review.py --through CL06
```

스크립트 이름은 기존 CL01–05 검수본을 재현하기 위해 유지했으며, `--through`는 CL01–CL30을 지원한다. 생성 영상 원음은 끄고 FINAL TTS만 얹으므로 효과음·음악 검수는 별도다.

명령은 `apps/editor`에서 실행한다. 이 검사는 읽기 전용이며 전체 빌드·테스트를 재실행하지 않는다.

```powershell
python scripts/validate-longform-av-contract.py --plan <chain-plan.json> --contract <av-contract.json> --tts-root <FINAL-03_tts-폴더>
```

## 현재 쿠퍼 계획에 적용한 진단

`av-beat-contract-diagnostic-v1.json`으로 CL01–06만 `--allow-partial` 검사했다. 이는 **진단이며 제작 준비 통과가 아니다**. 결과는 다음 네 가지 차단 항목이다.

| 샷 | 불일치 |
| --- | --- |
| CL01 | 계단 관련 문장 약 2.77–4.74초, 계획 화면 공개 6–7초 |
| CL02 | 착륙 후 빈 공간 관련 문장 약 1.20–3.45초, 계획 공개 5–6초 |
| CL05 | 가방 속 물체 설명 약 3.42–4.58초, 계획 노출 5.2–6초 |
| CL06 | 계약은 v4 영상 프롬프트를 참조하지만 `chain-plan.json`은 v2를 참조 |

현재 CL01–05의 국소 편집 후보는 `review/cl01-05-av-review-v1/`에 있다. **CL06 생성 전에는** 최신 연출·프롬프트·연결 계획을 같은 개정으로 맞추고, CL07 시작과 실제 CL06 사용 종료 화면을 이어서 검수해야 한다. 전체 30샷 계약이 완료되기 전에는 새 기준의 제작 준비 PASS라고 표시하지 않는다.
