# D.B. Cooper 270초 연결 시사본 QC v2

상태: **구조·음성 배치 확인, 연출 잠금 보류**. 이 판정은 `270s-connected-preview-v2/db-cooper-270s-timing-preview.mp4`와 `render-report.json`, 30샷 연출 계획 v2를 대조한 관리자 검토다. 시사본 화면은 행동·음향을 적은 임시 카드이며 실제 생성 장면이 아니다.

## 확인된 사항

- 7개 검토용 TTS의 글자별 정렬을 30개 샷 경계에 맞춰 분절·배치했다. 원본 Scene MP3는 보존했다.
- 영상과 음성 스트림 모두 **270.000초**, 화면은 **1920×1080 / 16:9**이다. 30샷, 화면 카드 90장. 각 음성 구간은 사용 클립 길이 안에 있다.
- 정렬 보고서 대비 분절 오차의 최댓값은 0.016초다. v1과 v2의 음성 WAV 해시는 동일하므로 v2는 대본이나 낭독을 바꾸지 않았다.
- 실제 내레이션 사이의 간격은 3초 이상 24곳, 4초 이상 11곳, 4.5초 이상 7곳이다. 최장은 **CL15에서 CL16으로 넘어가는 4.725초**다. 이 수치는 실제 효과음이 없는 검토용 음성의 간격이며, 화면 사건이 충분한지 자동으로 증명하지 않는다.

## 잠금·Story Gate 판정

**SCRIPT_DIRECTING_LOCK: 보류. 관리자 Story Gate: 미진행.** 기존 사전 검토는 `REVISION_REQUIRED`였고, 새 계획의 움직임과 효과음은 아직 글자 카드로만 표현돼 있다. 따라서 긴 비음성 구간이 실제 화면 행동과 소리로 유지되는지, CL01/CL29가 동일 구조로 이어지는지, 이미지 스타일이 일관되는지 검증하지 못했다. 30샷 후보 매니페스트와 Scene graph 후보는 갱신했지만 승인 상태로 승격하지 않았다.

추가로 AGENTS.md가 요구하는 story/audio·visual/clip 역할 자체 QC를 요청했으나 역할 실행기가 `Unknown model gpt-5.6`을 반환해 시작되지 않았다. 관리자 검토를 역할별 자체 QC로 표시하지 않는다. 정식 개발 잠금에 필요한 대본 QC, 사전 연출 검토, Visual Skeleton, 20–30초 시퀀스 QC의 전 항목을 PASS로 꾸며 넣지 않으며 `validate_script_directing_lock.py`도 잠금 파일이 없으므로 실행하지 않는다.

다음 검토에는 실제 스타일의 짧은 연속 모션 샘플과 임시 효과음 또는 동등한 애니매틱이 필요하다. 특히 120–150초와 210–240초를 우선 확인하고, 유지 근거가 약하면 클립 길이·내레이션·전체 270초 구조를 대본 단계에서 다시 조정한다.
