# D.B. 쿠퍼 v3 — MASTER BOARD 01 / VISUAL BIBLE LOCK

상태: 메인 스타일 보드 제작용 고정 사양. 이미지의 시각적 완성도와 별도로 실제 10초 I2V 연속성 QC 통과 전까지 전체 프로젝트 95점 최종 승인을 선언하지 않는다.
대상: 대본 v3, 총 길이 목표 4분 30초, TTS 1.1배속, NON_REALISTIC_STYLIZED hand-drawn 2D historical action mystery.

## 1. 스타일 불변 규칙
- 실사/사진풍/광택 3D/실제 카메라 피사계 심도 금지. 손그림 잉크, 다양한 두께의 각진 윤곽선, 브러시 그레인, 깊은 차콜 명암을 사용한다.
- 색채 기준: charcoal #1A1A1A, steel blue #2E4B6B, slate #6B7C8F, ivory #E8DCC6, restrained amber #B58945. 색은 가이드이며 샷 전체의 명암 리듬을 우선한다.
- 어둡더라도 주요 피사체는 배경과 최소 한 단계 이상 분리되게 한다. 앰버는 경고등·창문·종이에서 의미 있게만 사용한다.
- 보드는 여러 패널을 배치할 수 있으나 실제 16:9 클립 마스터프레임은 한 화면/한 사건만 그린다. 임의 텍스트, 도식, 워터마크, 과도한 포스터 콜라주를 샷에 옮기지 않는다.

## 3. 장면-시각 앵커 연결
- SC01: 1971년 재이륙 후 야간 비행, 후방 하부 계단이 열려 있음. 직접 점프/인물의 착지 장면 금지.
- SC02: 포틀랜드 출발(오후) 객실. 쪽지→서류가방→승무원 별도 메모의 순서를 구분.
- SC03: 시애틀 착륙과 승객 하차/돈·낙하산 인계, 이후 재이륙. 같은 기체·객실·커튼 사용.
- SC04: 후방 계단 조작 → 경고등/계기 변화 → 리노 착륙 뒤 빈 객실. 누구도 점프를 직접 보지 못함.
- SC05: 북서부 숲/강의 수색. 구체적인 헬기 대수·방향·날짜는 근거 없으면 실제 재현처럼 표현하지 않음.
- SC06: 1980년 **낮**, 컬럼비아강 강변 발견. 흠집·오염·젖은 듯한 훼손 지폐가 일부만 보임.
- SC07: SC01의 동일 계단 구조/카메라 축을 재사용. 첫 장면과 다른 관점의 카메라 후퇴. 생존/사망 단정하지 않음.

- [ ] 1971년 낮/밤과 1980년 강변의 시간대가 분리됨.
- [ ] CASH80-01: 세 묶음의 오래 훼손된 $20 지폐.
- [ ] 추락/착지/생존 모습 또는 단정적 설명 없음.
- [ ] 텍스트/표식은 편집 합성. 생성 이미지에 임의 쪽지 원문/계기 텍스트 고정 금지.
