0. 비실사 스타일 절대 원칙

이 프로젝트의 역사·미스터리 LONGFORM 최종 화면은 **실사형으로 제작하지 않는다**.

금지:
- 포토리얼/실사/하이퍼리얼
- 라이브액션처럼 보이는 화면
- 다큐멘터리 재연처럼 보이는 역사 장면
- 알 수 없는 얼굴·의상·생활상을 정확한 사실처럼 채워 넣는 가짜 고증
- "사실적인 영화 재현"을 품질 목표로 사용하는 프롬프트

실제 사진·화석·발굴·박물관 자료는 FACT/SHAPE 참고자료로는 사용할 수 있다. 그러나 최종 화면은 반드시 스타일라이즈드 역사 판타지/시네마틱 애니메이션 언어로 변환한다.

빠른 전개의 흥미는 실사 디테일에서 얻지 않는다. 시선을 강하게 끄는 색·형태·레이어·과장된 원근, 전경 패럴랙스, 공간 관통, 스케일 전환, 아크/오비트, 그래픽 매치, 가림막 전환, 속도 대비와 같은 **애니메이션형 카메라 연출**에서 얻는다.

고증은 모든 미세한 생활 디테일을 복원하는 작업이 아니라, 확인된 사실·증거·시대 범위·유물 형태·지리 관계를 왜곡하지 않는 선에서 적용한다. 알 수 없는 부분은 스타일화·생략·실루엣·상징 공간으로 처리한다.

1. 제작 원칙
특정 사건이나 인물을 중심으로 서사의 범위를 좁힌다. 정보의 양보다 행동·변화·발견의 연결로 몰입을 만든다. 인물에 집중한다는 것은 얼굴을 확대한다는 뜻이 아니다. 풍경·집단·사물도 중심 사건을 전진시키면 사용한다.

내용이 차분하거나 긴 시간을 다뤄도 연출은 스피디하게 유지한다. 모든 클립은 시작부터 목적 있는 카메라 모션에 진입하고, 3~4초 이내에 시선 이동에 따른 새로운 정보나 시각적 변화를 제공한다. 클립 전체 길이를 3~4초로 고정하지 않는다. 긴 클립은 첫 발견 이후에도 행동·구도·상황 변화로 진행한다.

주요 행동 하나, 주 카메라 움직임 하나, 명확한 시각적 보상 하나를 기본으로 한다. 주변의 자연스러운 움직임은 허용하되 별도의 사건을 과밀하게 넣지 않는다. 적극적인 카메라를 유지하면서 핵심을 알아볼 짧은 시간은 확보한다.

세밀한 접촉·조정·마찰·무게 전달·작은 물리 반응이 성공해야만 의미가 성립하는 장면은 우선 제외하거나 재설계한다. 이는 모든 생성 도구의 절대적 한계를 선언하는 규칙이 아니라, 이번 테스트에서 확인한 위험을 줄이기 위한 제작 선택이다.

2. 전체 제작 흐름
핵심 메시지·중심 질문 → 구현 가능한 서사 → 대본·화면 공동 설계 → 위험 장면 사전 테스트 → TTS 확정 → 실제 시간별 클립 배정 → 클립 연출 디렉션 확정 → 공통 레퍼런스 → 시작·종료 상태의 이미지화 → 영상 생성 → 편집·검수.

레퍼런스의 개념 설정은 서사 단계부터 진행하며, 실제 제작은 장면에서 필요한 인물·공간·소품이 정해진 뒤 수행한다. 연출 디렉션과 레퍼런스가 충돌하면 이미지 생성 전에 해결한다.

기획	사건·인물 하나, 전달할 의미, 중심 질문, 마지막 보상	기획 카드
서사	행동·변화·발견의 인과와 다음 장면을 볼 이유	주요 장면 구성표

사전 검토	핵심 장면의 구현 위험·흥미·대체 가능성	위험 장면 테스트 또는 대체안

영상	이미지 사이의 행동과 카메라 진행	생성 클립·검수 기록

3. 서사와 대본 기준
정보 나열로 시작하지 않는다. 사건의 진행이나 질문에 먼저 진입하고 필요한 배경은 진행 중에 제공한다. 각 주요 장면은 ‘무엇이 일어나는가 / 무엇이 달라지는가 / 왜 다음을 보는가’에 답해야 한다.

내레이션은 사실·시간·인과·의미를 담당하고, 화면은 행동·공간·발견·감정을 담당한다. 대본의 문장을 그대로 재현할 의무는 없지만, 화면이 사실이나 원인 관계를 왜곡해서는 안 된다. 역사물은 사실·해석·재현·시각적 비유를 제작표에서 구분하며, 창작된 행동을 확인된 사건으로 내레이션하지 않는다.

장면 선택 전에 아래 순서로 판단한다.

중심 이야기를 진행시키는가?
시청자가 화면에서 얻을 명확한 변화가 있는가?
3~4초 이내 카메라 이동으로 그 흥미를 전달할 수 있는가?
세밀한 물리 반응 없이도 의미가 읽히는가?
반복 생성할 가치가 충분한가? 부족하면 장면 자체를 바꾼다.
4. TTS와 시간 배정
실제 TTS 생성 후 타임코드를 확정한다. 한 문장에 여러 클립을 배정하거나 여러 문장을 하나의 클립으로 묶을 수 있다. 컷 경계는 문장 부호보다 정보·행동·시선의 변화로 결정한다.

각 클립에는 타임라인 시작/종료, 편집 사용 길이, 도구의 실제 생성 길이, 원본에서 사용할 구간, 핵심 공개 마감 시점을 별도로 기록한다. 핵심 공개는 편집 사용 시작부터 3~4초 이내다. 사용할 클립이 더 짧으면 그 안에 완료한다.

도구가 10초를 생성한다고 10초를 모두 사용할 필요는 없다. 반대로 짧은 행동을 생성 길이에 맞추어 억지로 늘리지 않는다. 초 단위 지시는 목표이며 실제 결과에서 발생 시점을 확인한다. TTS가 바뀌면 시간 배정과 공개 시점을 다시 검토한다.

아래 필드를 클립마다 작성한다. 모호한 ‘역동적·영화적’ 표현만으로 통과시키지 않는다.

인물의 이동과 카메라의 이동을 별도로 적는다. ‘오른쪽 이동’은 화면 기준인지 공간 기준인지 명시한다. 카메라가 이동해도 인물을 화면 왼쪽에 유지할 수 있으므로, 화면상 위치와 실제 위치를 혼동하지 않는다.

6. 카메라 설계 기준
샷 크기, 높이·각도, 이동, 공개 대상을 조합한다. 인접 클립에서 같은 구도·속도·대상을 기계적으로 반복하지 않는다. 연속 동작의 연결이 필요하면 방향을 유지하고 다른 요소로 대비를 만든다.

목적	사용할 조합	반드시 정할 것
이동의 추진력	지면 가까운 와이드+측면 트래킹	따라갈 대상·전경·목적지
숨은 공간 공개	트럭 이동+가림막 리빌	실제 시야를 가리는 물체와 공개 대상
규모 확장	달리 아웃 또는 크레인 상승	가까운 정보와 전체 상황의 차이
공간 진입	인물 뒤 팔로우+전진	통과 경로·장애물·도착 구도
관찰 대상 연결	오버숄더+짧은 측면 이동	시선 대상이 나타나는 시점

팬·틸트는 고정 위치에서 회전하며, 트럭·달리는 위치가 이동한다. 줌을 실제 이동의 대체로 사용하지 않는다. 랙 포커스는 보조적인 시선 전환이며 카메라 경로를 대신하지 않는다. 휩팬·과도한 회전은 목적과 연결이 명확할 때만 사용한다.

7. 공통 레퍼런스
반복 등장 인물은 얼굴·체형·의상·장비·상대 크기를 고정한다. 필요한 각도만 제작한다. 배경은 장소의 입구·통로·큰 장애물·주요 대상 위치와 빛의 방향을 기록한다. 같은 공간을 다른 시점에서 보여줄 수 있도록 공간 관계를 먼저 확정한다.

레퍼런스는 외형 일관성 자료이고, 클립 이미지는 행동과 촬영 구도를 담은 결과물이다. 레퍼런스의 정적인 자세를 모든 장면에 그대로 복제하지 않는다.

8. 시작·종료 이미지 제작 규칙
전체 카메라·행동 경로를 확정한 뒤 시작과 종료 시점의 화면을 추출한다. 두 이미지를 독립적인 ‘멋진 그림’으로 작성하지 않는다.

시작 이미지에는 행동이 시작 가능한 자세, 공간, 주목 대상, 이동 후 드러날 대상의 가림 상태가 있어야 한다. 종료 이미지에는 같은 세계에서 실제로 이동했을 때 가능한 관점과 결과가 있어야 한다. 카메라 이동으로 피사체의 크기·중첩·배경 관계가 어떻게 바뀌는지 명시한다. 대상 자체를 옮겨 카메라 이동처럼 보이게 만들지 않는다.

종료 상태는 항상 설계한다. 종료 이미지 파일은 도착 구도·정체성·특정 결과를 고정할 필요가 있을 때 제작한다. 시작과 종료가 비슷하다면 무조건 파일을 추가하지 말고 연출의 변화가 충분한지 먼저 확인한다.

연결 방식	적용
시작 이미지 단독	명확한 행동·이동을 자유롭게 시험하고 종료 상태를 지시할 때
시작+종료 이미지	도구가 지원하고, 중요한 도착 구도에 도달해야 할 때
실제 끝 프레임 연속	끊김 없는 다음 클립은 채택한 이전 클립의 사용 구간 끝 프레임을 추출해 입력
앵글 전환 컷	같은 장면이어도 새 시작 이미지를 제작하되 공간·시선·행동 연속성을 유지
연속 클립은 스틸만으로 속도가 전달되지 않으므로 이전 이동 방향·속도·동작 단계도 프롬프트에 기록한다. 생성 모델이 두 프레임 사이를 정확히 복원한다고 가정하지 않는다.

9. 짧은 생성 프롬프트 작성법
설계서는 상세하게 유지하고, 생성 지시는 실행에 필요한 내용만 남긴다. 내부 검수표·서사 해설을 그대로 붙이지 않는다. 중요한 지시를 먼저 쓰고, 유지·금지 조건은 해당 장면의 실제 위험에 한정한다.

시작 이미지 템플릿
레퍼런스: . . . . . .

종료 이미지 템플릿
시작 이미지와 동일한 인물·지형·빛을 유지한다. 카메라는 를 따라 로 이동했다. , , 을 로 보여준다.

영상 템플릿
, 연속 촬영, 정상 속도. . 카메라는 에서 로 을 따라간다. 사용 구간 시작 후 까지 를 드러낸다. . .

영문 입력을 사용할 경우 한국어 디렉션과 별개로 창작하지 말고 같은 뜻으로 압축 번역한다. 한국어·영문 버전을 나란히 검토한다.

10. 예시 연출 카드 — 눈보라 속 피난처 발견
상태: 공간·카메라 설계 예시. 실제 제작 전 시작/종료 구도의 공간 정합성 테스트가 필요하다. 특정 역사적 사건을 입증하는 장면이 아닌 재현 예시다.

필드	예시
STORY	인물이 추위를 피해 보호된 장소를 찾는다
시간	편집 사용 6초, 생성 길이는 도구 설정에 맞춤, 공개 목표 3초
ACTION	인물이 바위를 따라 오른쪽으로 걸어 동굴 입구를 향한다
SPACE	가까운 바위가 입구의 시야를 가림. 인물은 바위 뒤쪽 보행로, 카메라는 앞쪽의 평행 경로를 이동
START	낮은 와이드. 인물은 왼쪽 ⅓, 바위는 오른쪽 전경. 입구는 가려져 있음
CAMERA	지면 가까이에서 오른쪽으로 빠르게 측면 트래킹. 인물을 왼쪽 ⅓에 유지. 전경 바위는 시야에서 빠짐
REVEAL	3초 안에 오른쪽 중경의 동굴 입구와 희미한 내부 불빛이 나타남
END	인물·입구·그 사이의 이동 경로가 함께 읽힘. 인물은 계속 입구로 이동
HANDOFF	다음 컷은 내부에서 진입을 받아 이동 방향과 동작을 연결
RISK	바위가 실제로 입구를 가릴 수 있는 배치인지 검토. 비정상적인 지형 생성·보행 오류 시 경로 단순화
예시 시작 이미지 지시: ‘낮은 와이드 구도. 가죽옷을 입은 인물이 화면 왼쪽에서 오른쪽으로 걷기 시작한다. 가까운 오른쪽 바위가 뒤쪽 동굴 입구를 완전히 가린다. 인물의 보행로와 카메라의 평행 이동 공간이 확보되어 있다. 차가운 눈보라, 강한 브론즈-차콜 계열의 비실사 역사 판타지 애니메이션 프레임, 과감한 전경 패럴랙스와 깊이 레이어, 포토리얼 금지, 16:9.’

이 예시가 불씨·돌 장면보다 안정적으로 생성된다고 검증된 것은 아니다. 정밀한 손 접촉 의존도를 줄인 다음 테스트 후보이며, 보행과 공간 변화 역시 결과 검수가 필요하다.

11. 단계별 체크리스트
각 항목은 통과 / 수정 / 해당 없음으로 기록한다. 핵심 결함을 평균 점수로 상쇄하지 않는다.

한 번의 명확한 수정에도 같은 구조적 문제가 반복되면 장면 교체를 우선 검토한다. 모든 장면을 끝까지 살리는 것이 목표가 아니다.

이번 테스트의 교훈: 손으로 불을 감싸기와 돌로 바람을 막기는 미세한 행동·접촉·불꽃 반응의 정합성이 필요했고, 시각적 보상에 비해 반복 수정 비용이 컸다. 불의 크기·돌의 크기·시작 자세가 지시와 달랐는데도 다음 단계로 넘긴 점을 방지해야 한다.

13. 실무 운영 단위
전체를 생성하기 전에 대표 구간 3~5클립으로 서사 연결·카메라 다양성·이미지 구현성을 시험한다. 대표 구간에는 인물 이동, 공간 공개, 규모 확장 등 서로 다른 연출을 포함한다.

하나의 제작표에서 클립 ID로 TTS 구간, 연출 카드, 레퍼런스, 시작/종료 이미지, 영문·한글 프롬프트, 생성 영상, 채택 사용 구간, 검수 결과를 연결한다. 생성 전 미리보기에는 이미지와 연출·시간·프롬프트를 함께 보여준다. 운영 시 HTML 검토 화면으로 구현할 수 있다.

운영 기준: 서사는 좁게, 전개는 빠르게, 행동은 명확하게, 카메라는 목적 있게. 이미지는 승인된 연출 디렉션을 구현하고, 실제 결과가 기준을 충족할 때만 다음 단계로 넘긴다.
